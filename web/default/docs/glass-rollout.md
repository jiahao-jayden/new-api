# 控制台玻璃设计语言迁移

## 范围与优先级

本轮将已确认的 API 密钥页玻璃设计语言迁移到其余现有页面，以及弹窗、抽屉、菜单、选择器、提示等共享组件。迁移只调整视觉、布局与滚动容器，不新增产品功能，不删除现有字段、操作、文案或权限。

以下官网入口保持原样，不套用控制台玻璃皮肤：

- `/`：原独立官网。
- `/dashboard/overview`：控制台内嵌的原官网。

原官网 HTML、其内容与跳转逻辑不在本轮重设计范围内。Keys 试点中此前已获用户批准的内容调整，不应被误认为本次整站迁移可以继续删改功能的授权。

实现依据的优先级为：现有业务代码、真实数据与权限约束 → 用户确认的设计规范 → 逐页生成的视觉参考。生图中的示例金额、字段、文案、按钮或功能，不构成新增需求；与现有代码不一致时必须保留实际产品内容。

## 材质与色彩

| 元素             | 规范                                                          |
| ---------------- | ------------------------------------------------------------- |
| 玻璃表面         | 白色填充，透明度 `2%`；不是不透明灰色卡片                     |
| 主文字与普通图标 | 白色 `80%`                                                    |
| 次级文字         | 白色 `60%`                                                    |
| 组件背景模糊     | 卡片 `blur(100px)`；按钮、输入框与弹出内容保留 `blur(24px)`；不应用于页面背景 |
| 高光边缘         | `0.5px` 环形白色渐变，左上与右下约 `9%`，右上与左下约 `55%`   |
| 内部纹理         | 不添加玻璃纹路、划痕、噪点图层或游戏素材纹理                  |
| 页面壁纸         | 用户原图直接显示，不叠加暗罩、滤镜或全屏高斯模糊             |

高光边缘与组件外轮廓重合，不能向内错位。装饰图层不接收指针事件，不覆盖真实点击区域或焦点。常规单行按钮、筛选项与搜索框使用跑道型大圆角；大面板保持清晰、克制的圆角层级。

颜色表达仍服从真实语义：错误、危险操作、成功状态、数据系列和支付品牌不能因统一材质而失去必要的区分。不得用视觉样式改变禁用状态、选中值或权限判断。

### 文字遮挡与对比度例外

透明材质不是让上下两层文字重叠显示。以下暗背衬用于遮挡底下内容，`2%` 白色表面仍保留：

- 弹出菜单、选择器及类似小型悬浮内容采用约 `88%` 暗色背衬。
- 表格固定操作列采用约 `94%` 暗色背衬，避免横向滚动时底层单元格文字透出。
- 页面壁纸不叠加暗罩。模态弹窗打开时保留焦点用的半透明遮罩，但遮罩本身不使用模糊；毛玻璃只属于弹窗卡片。

## 页面结构

### 顶部与底部导航

- 顶部 Logo、标题、余额等内容为独立悬浮岛；不再增加贯穿页面的顶栏分割线、整条遮挡层或整条模糊层。
- 顶部岛沿用玻璃填充与高光边缘。
- 底部 Dock 高度 `64px`，只显示图标，不显示常驻文字（包括选中项）。保留异形黑色底座，只有黑色栏本身不透明，外围区域保持透明。文字提示在移入图标或键盘聚焦时立即显示。
- Dock 是固定覆盖层，不再占据整条底部布局空间。正文延伸到视口底部；黑色轮廓以外的区域允许点击、滚动穿透到页面，不能提前裁切卡片。
- 控制台主页 `/dashboard/overview` 共用同一个 Dock；导航独立使用 `data-console-dock-skin`，不再依赖页面是否启用玻璃主题。独立官网及嵌入 HTML 的内容、配色保持不变。
- 不使用青色圆环作为选中标记。
- 导航目标、普通用户与管理员的入口过滤、系统设置分类和子页可达性保持既有逻辑。

### 图标

共享图标适配器使用 Untitled UI 线性图标替换旧游戏栅格素材。保留现有图标组件的尺寸、颜色继承、事件、引用和无障碍标签契约；装饰图标不重复朗读。不得用图标替换使实际操作失去名称或键盘可达性。

### 内容与滚动

- 控制台采用固定工作区；长列表、表格、详情和表单在各自内容区内部滚动，避免无意义的整页上下漂移。
- 不以隐藏字段、减少操作或截断内容来强行塞进一屏。
- 窄屏允许合理堆叠和表格横向滚动，仍须保留完整内容、筛选、分页或现有连续列表机制。
- 右侧详情沿用贴边轮廓与细白高光；内容与顶部悬浮岛留出距离。装饰边框不能遮挡正文、按钮或滚动区域。

## 弹窗与共享控件

弹窗、抽屉、菜单、选择器、提示及内部表单统一使用同一材质系统。共享组件优先承担外观规则，页面仅补充必要的布局差异。

迁移不得改变打开与关闭条件、确认流程、焦点管理、键盘操作、表单校验、加载状态、错误信息或提交回调。Checkbox、Radio 与 Switch 保留 Base UI 的状态和交互机制，只替换视觉标记；半选状态只能有一个可见标记，不叠加旧素材伪元素。

## 行为安全审查

以当前工作树与 `HEAD` 的差异为基线，对本轮非 Keys 试点的 UI 修改进行了只读审查：

- 公共与认证布局主要新增皮肤标记；登录、OAuth、路由跳转与权限判断未改。
- 模型详情增加装饰边框和滚动容器，保留现有数据、标签页、回调和焦点引用。
- 系统设置保留原字段、操作、提交逻辑及所有 `40` 个子页入口；少数条件表达式和数字解析写法属于等价代码整理。
- 未发现后端、API 层、计费业务、路由定义、状态仓库或六种语言翻译正文的改动。翻译扫描报告不属于用户文案变更。
- 原官网 HTML 与导航逻辑未改。

独立运行的相关测试为 `15` 个文件、`53` 项通过、`0` 项失败，覆盖导航权限、系统设置入口、菜单兼容、图标契约、官网跳转、渠道折扣、模型价格、币种显示和人民币充值。发现的 Checkbox 半选重复标记已在共享样式中消除。

上述结论限于已审查差异与已运行测试，不等同于所有页面、屏幕尺寸、弹出状态及真实业务操作都已完成端到端验收。

## 验收边界

- 当前本地环境已登录且已经初始化。登录、注册、OAuth 和初始化页面的部分访问会被既有 guard 重定向；不能把这些重定向记录为相关表单的视觉或提交成功验收。
- 不自动访问 `chat2link` 外部地址，以免将现有 API Key 等敏感参数带到外部服务。
- 视觉验收结果、未覆盖状态及截图记录由主验收文档维护，见 [design-qa.md](../design-qa.md)。本文件不宣称所有视觉状态已验证。
- 本轮文档与 UI 工作不授权修改数据库、服务器配置、支付设置或线上业务数据；提交、推送与部署遵循用户另行授权。
