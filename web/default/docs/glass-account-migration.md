# Glass account migration — 2026-09-16

## Scope

Wallet and personal profile extend the user-approved API key design. This is a visual migration only: the original website, billing formulas, payment requests, authentication, saved settings, provider bindings and permission checks are unchanged.

## Direction contract

THESIS: Keep balance and identity readable while payment and account controls remain easy to find; remove the old game-frame density.

OWN-WORLD: The approved nebula backdrop, white 2% frosted surfaces, half-pixel white conic edge highlights, 80% primary and 60% secondary white text, thin line icons, pill actions.

STORY: Check balance, add funds, redeem or share referrals; inspect identity, change notifications, language, currency and security settings.

FIRST VIEWPORT: Wallet has a narrow balance column beside recharge, followed by a separate full-width referral region. Profile has a fixed identity rail beside independently scrolling settings; mobile uses a single bounded scrolling column.

FORM: Existing application controls and approved keys material; user-pinned direction, no new concept selection.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Implementation

- `src/styles/glass-account.css`: page-local layout and semantic accents. The shared console skin supplies buttons, input material, card edges, overlays and icon mapping.
- Wallet retains all payment gateways, loading/minimum amount/compliance states, subscriptions, history, transfer and redemption controls. Only the provider icon carries blue (Alipay), green (WeChat) or violet (Stripe); no opaque brand-colored panel.
- Profile retains all conditional binding providers, administrator-only upstream notifications, every notification method, currency/language state, password/access-token/account deletion, Passkey, two-factor authentication and optional check-in.
- Loading skeletons, keyboard handling and labels remain from existing components. No translations or interface wording changed.
