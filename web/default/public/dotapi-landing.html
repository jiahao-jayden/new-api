怎么接入

第一步

注册账号

邮箱注册，不需要企业资质，也不需要预先充值。

第二步

选择模型

在控制台勾选需要开通的模型，同一把密钥可以同时调用它们。

gpt-5.1
claude-opus-4.5
gemini-3-pro
deepseek-v3.2
第三步

替换 base_url

把官方地址换成 DotAPI 的地址，填入你的密钥，其余参数保持原样。

base_url = "https://api.dotapi.cn/v1" api_key = "sk-dot-••••••••" model = "gpt-5.1"
第四步

发起调用

先在控制台的调试台里发一条测试请求，确认返回正常再接到线上。

→ POST /v1/chat/completions ← 200 OK · 1.24s · 312 tokens
输入一条消息试试…

现成工具直接可用

凡是支持自定义 OpenAI 地址的客户端和框架，填地址和密钥就能用，不需要额外适配。

用量与日志可查

每一次调用都记录模型、token 数、耗时和状态码，可按密钥、按项目筛选，账单按同样的口径生成，随时能对上。

密钥按项目隔离

可以为每个项目单独建密钥，分别设置额度上限、可用模型和调用频率。某把密钥泄露时单独吊销即可。

常见问题

你可能会问

请求多走一跳。好处是一把密钥能调多家模型、可以在国内网络环境下直接访问、账单和日志集中在一处；代价是多出几百毫秒的转发耗时，并且你需要信任我们这一层。除此之外，返回内容与官方接口一致。

默认只记录元数据：模型名、token 数、耗时、状态码。请求体和返回体不落盘。如果你在控制台主动打开"保留正文"用于排查问题，保留期为 7 天，可随时关闭并删除已有记录。

价格变动会在生效前 7 天在公告和站内信中通知，已充值余额不受影响。模型下线同样提前公告，并在文档里给出可替代的模型名，方便你改一个字符串完成迁移。

能。未消耗的余额可以在控制台提交退款申请，原路退回，一般 3 个工作日内到账。赠送的额度不参与退款。

chat/completions、embeddings、images、audio 与 responses 接口都支持，含流式输出、函数调用和多模态输入。官方 SDK 只需改 base_url，无需替换成我们的 SDK。

控制台内提工单，工作时间内一般一小时内回复。网关本身的故障会同步更新到状态页，包括影响范围和恢复时间。
